📧 البريد الإلكتروني (SMTP)

← الإعدادات

فعّل ده عشان العملاء يوصلهم إيميل بجانب رسالة الواتساب (تأكيد الطلب، عرض السعر، إغلاق الطلب...).

⚠️ مهم: استضافة Railway بتمنع الإرسال عن طريق SMTP (منافذ ٥٨٧/٤٦٥ مقفولة)، فالطريقة دي بتفشل على السيرفر. الطريقة اللي بتشتغل هي Brevo — بترسل الإيميل عن طريق الويب (HTTPS) وفيها باقة مجانية ٣٠٠ إيميل/يوم. اختار Brevo تحت وحُط مفتاح الـ API.

من حساب Brevo → SMTP & API → API Keys. سيبها فاضية لو مش عايز تغيّرها.

خانات الخادم (Host / Port / اسم المستخدم / كلمة المرور) مطلوبة بس مع SMTP. أما اسم وإيميل المُرسِل فمطلوبين في الحالتين (Brevo كمان).

تُحفظ مشفّرة في قاعدة البيانات. سيبها فاضية لو مش عايز تغيّرها.

✉️ إرسال رسالة اختبار

احفظ الإعدادات الأول، وبعدين ابعت رسالة اختبار للتأكد إنها شغّالة.

✅ إعداد Brevo (الطريقة الموصى بها)

  1. ادخل على brevo.com واعمل حساب مجاني (الباقة المجانية ٣٠٠ إيميل/يوم).
  2. من إعدادات الحساب: Senders, Domains & Dedicated IPs → أضف info@one4in.com كـ Sender وفعّله (هيجيلك إيميل تأكيد).
  3. روح على SMTP & API → API Keys → Generate a new API key باسم "ONE Tracking".
  4. انسخ المفتاح (بيبدأ بـ xkeysib-) وحُطه في خانة مفتاح Brevo API فوق.
  5. حُط إيميل المُرسِل = info@one4in.com واسم المُرسِل باسم الشركة، فعّل الإرسال، احفظ، وابعت رسالة اختبار.

ملحوظة: عشان أفضل وصول للإيميلات ومنع السبام، يُفضّل توثيق الدومين (SPF/DKIM) من Brevo لاحقًا — بس مش شرط عشان تبدأ.

🔑 إزاي تعمل App Password لجوجل (لطريقة SMTP فقط)

  1. ادخل على myaccount.google.com بحساب info@one4in.com
  2. فعّل التحقق بخطوتين (2-Step Verification) لو مش مفعّل.
  3. ادخل على App passwords (كلمات مرور التطبيقات) → اعمل واحدة جديدة باسم "ONE Tracking".
  4. انسخ الـ 16 حرف اللي هيطلعوا وحطهم في خانة كلمة المرور فوق.
